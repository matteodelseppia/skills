# Skills

## Installation

Install all skills in this repository globally with the Skills CLI:

```bash
npx skills add matteodelseppia/skills -g -y
```

The skills are supported for GitHub Copilot, Pi, Crush, and OpenCode.

### Install a specific skill

To install only one skill, append its name to the repository reference with `@`:

```bash
npx skills add matteodelseppia/skills@diataxis -g -y
```

Replace `diataxis` with the skill you want to install, such as `software-design-reviewer`.
